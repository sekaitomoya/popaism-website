# Brillante — Shopifyテーマ

[tokitokitoki.base.ec](https://tokitokitoki.base.ec/)（-BRILLANTE- ブリランテ大阪）をShopifyへ移行するためのオリジナルテーマです。
デザインは [NOWALL](https://nowall-online.com/) のUIを参考に、白背景・大文字見出し・ピル型ボタンを基調としたミニマルなセレクトショップ向けレイアウトになっています。

**このテーマはUI（ストアフロントの見た目）のみを実装しています。** 商品データ・決済・配送などはShopify管理画面での設定が必要です。

## 構成

```
shopify-theme/
├── layout/theme.liquid        # 全ページ共通レイアウト
├── config/                    # テーマ設定（カラー・フォント等）
├── locales/ja.default.json    # 日本語UIテキスト
├── templates/                 # 各ページのテンプレート（JSON）
├── sections/                  # セクション（カスタマイズ可能なUI部品）
├── snippets/                  # 商品カード・価格・アイコン等の部品
└── assets/                    # CSS / JavaScript
```

### 主なUI機能

- 告知バー（複数メッセージのローテーション対応）
- 検索バー付きヘッダー＋ドロップダウン付きグローバルナビ（モバイルはドロワーメニュー）
- ヒーロースライドショー（自動再生・ドットナビ）
- 商品カード：ホバーで2枚目の画像に切替、SOLD OUT / SALE バッジ、ブランド名表示
- 商品ページ：サムネイル付きギャラリー、バリアント選択（ピル型）、数量ステッパー、スピード購入ボタン
- コレクションページ：並び替え・ページネーション
- カート、検索、ブログ、お問い合わせフォーム、404
- ニュースレター登録（フッター＋専用セクション）

## プレビュー / デプロイ方法

[Shopify CLI](https://shopify.dev/docs/api/shopify-cli) を使用します。

```bash
cd shopify-theme

# 開発ストアでライブプレビュー
shopify theme dev --store <your-store>.myshopify.com

# 未公開テーマとしてアップロード
shopify theme push --unpublished --theme "Brillante"
```

## 移行時にShopify管理画面で設定するもの

### 1. コレクション（BASEのカテゴリに対応）

BASE側のカテゴリ構成に合わせて、以下のコレクションを作成してください。

| 親カテゴリ | 子カテゴリ |
| --- | --- |
| 靴 | スニーカー |
| 小物 | 帽子 / 財布 / 鞄 / マフラー |
| アウター | ジャケット / カーディガン |
| パンツ | — |
| トップス | Tシャツ / パーカー / シャツ / スウェット |

あわせて「新着商品（New Arrivals）」の自動コレクションを作成すると、トップページの NEW ARRIVALS セクションに割り当てられます。

### 2. メニュー

- `main-menu`（メインメニュー）: HOME / ABOUT / ALL ITEM / CATEGORY（上記コレクションを階層で） / BLOG / CONTACT
- `footer`（フッターメニュー）: ABOUT / お問い合わせ など

ナビゲーションのドロップダウンは、メニューの階層（親→子→孫）がそのまま反映されます。

### 3. ページ

- `page.contact` テンプレートを割り当てたお問い合わせページ
- ABOUT ページ（ショップ紹介）

### 4. ポリシー

設定 > ポリシー で「プライバシーポリシー」「特定商取引法に基づく表記」等を登録すると、フッターに自動表示されます。

### 5. テーマカスタマイズ

テーマエディタ（カスタマイズ）から、ロゴ画像・スライドショー画像・告知バーの文言・各セクションの割当コレクション・SNSリンク（テーマ設定 > SNS）を設定してください。

### 6. 商品データ

BASEの商品CSVをエクスポートし、Shopifyの商品インポート形式に変換して取り込みます。ブランド名は Shopify の `vendor` フィールドに入れると商品カード・商品ページに表示されます。
